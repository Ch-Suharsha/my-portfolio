# Suharsha Cheedalla Portfolio

Vite + React + TypeScript + Tailwind CSS portfolio foundation deployed with GitHub Pages.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis
- Phosphor Icons

## Local Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

- **Frontend:** GitHub Pages deployment runs from `.github/workflows/pages.yml` and publishes the Vite `dist` output.
- **Chat Assistant API:** The serverless function under `api/` is deployed on Vercel.
